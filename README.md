# Simple Timer

A huge, minimal stopwatch + countdown timer with dark mode. Single `index.html`, no build step, no dependencies.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

**Vercel**
```bash
npx vercel
```
(or import the repo on vercel.com — framework preset: *Other*)

**GitHub Pages**
1. Push to a GitHub repo.
2. Settings → Pages → Deploy from branch → `main` / root.

## Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Start / pause |
| `R` | Reset |
| `L` | Lap (stopwatch) or +1 min (timer) |
| `↑ / ↓` | +1 / −1 min (timer) |
